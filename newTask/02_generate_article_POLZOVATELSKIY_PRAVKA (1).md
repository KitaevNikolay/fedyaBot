# ПРАВКА 2: generate_article — ПОЛЬЗОВАТЕЛЬСКИЙ промт (файл 7-7)

## ЧТО ДОБАВИТЬ

Найти в промте блок «## Входные данные»:

```
** Тема статьи `(article_subject)`: `{{ article_subject }}`
** Вопросы, собранные для раскрытия темы `(QUESTION.content)`: `{{ QUESTION.content }}`
** Дата актуальности материала `(today)`: `{{ today }}`
```

После строки с {{ today }} добавить:

```
** Стиль автора `(author_name)`: `{{ author_name }}`
```

## ИТОГОВЫЙ ВИД БЛОКА:

```
## Входные данные

** Тема статьи `(article_subject)`: `{{ article_subject }}`
** Вопросы, собранные для раскрытия темы `(QUESTION.content)`: `{{ QUESTION.content }}`
** Дата актуальности материала `(today)`: `{{ today }}`
** Стиль автора `(author_name)`: `{{ author_name }}`
```

## КАК НАСТРОИТЬ В BOTHELP

Перед шагом generate_article добавить шаг с кнопками выбора автора:
[Евгения Мемрук] [Алексей Иванов] [Марат Самитов] [Надежда Самкова] [Оксана Каверина] [Без стиля]

Клик на кнопку → записывает значение в переменную author_name.
Если выбрано «Без стиля» — переменная остаётся пустой.
